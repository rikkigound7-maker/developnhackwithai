How to use Claude Code with a custom API base URL

Set ANTHROPIC_BASE_URL, the key and a model id, pay by UPI, and switch models inside a session with /model.

What you need

  • Claude Code installed and available as claude in your shell.
  • An sk- key from Hack & Develop With Ai.
  • Two minutes for the environment variables.

Set the environment

Claude Code uses the Anthropic format. Put these in your shell profile (~/.zshrc or ~/.bashrc) or export them for the current terminal: 

export ANTHROPIC_BASE_URL="https://freeai.hackdevelopwithai.com"
export ANTHROPIC_API_KEY="sk-..."
export ANTHROPIC_MODEL="anthropic/claude-sonnet-5"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="deepseek/deepseek-v4-flash"

The Anthropic base URL stops before /v1; the SDK adds the version path itself. The OpenAI-compatible base URL includes /v1. Both use the same key.

Set ANTHROPIC_MODEL. Without it, Claude Code sends its own built-in model names, which are not in the catalogue, and the request fails. The value must be a model id from the catalogue, for example anthropic/claude-sonnet-5 or anthropic/claude-opus-5.5.

Run Claude Code

claude

If Claude Code asks whether to use this API key, choose Yes. Then send a normal prompt. A small test: ask it to explain a file in the current directory. If the answer arrives, the base URL and key are correct.

Switch models inside a session

Run /model anthropic/claude-opus-5.5 to escalate a hard task, or /model anthropic/claude-haiku-5.5 for a quick edit. The key and base URL stay the same. This is the practical advantage of one gateway: you can move between frontier and fast models without another account. 

/model anthropic/claude-opus-5.5
/model anthropic/claude-sonnet-5

FAQ

Claude Code setup questions.

Do I need an Anthropic account?
No. Use the key from Hack & Develop With Ai and point ANTHROPIC_BASE_URL at the gateway. The Anthropic SDK format is the same.
Why do I need ANTHROPIC_MODEL?
Claude Code otherwise sends its own built-in model names. Those names are not in the catalogue, so the request fails. Set the variable to a model id from the catalogue.
Can I use the same key for Cursor and Codex?
Yes. The same key works across Claude Code, Codex, Cursor, Cline, OpenCode and Kilo Code. Each client needs the right base URL format.

Which model should I start with?
