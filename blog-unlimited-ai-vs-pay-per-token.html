Unlimited AI API vs pay-per-token

Why agent loops burn tokens, when a metered balance is enough, and when a fixed unlimited plan is the cheaper and calmer choice.

A chat message is a few hundred tokens. An agent run is different. The agent reads files, calls tools, retries, summarises, asks for another edit and repeats. The token count grows with every loop, and a metered bill grows with it.

Why agents burn tokens

  • Context is re-sent. Each turn carries the conversation and the files again.
  • Retries are normal. A failed test or a bad diff means another loop.
  • Tools add output. Shell output, search results and logs all become tokens.
  • Long sessions grow. A refactor can run for hours, not minutes.

None of this is waste. It is how an agent works. The problem is that a per-token price turns normal agent behaviour into an unpredictable invoice.

What unlimited means here

On Pro, Max and Ultra there is no token quota, no 5-hour quota, no weekly quota and no monthly request cap. You are not billed per token. The plan decides the model access, the number of parallel sessions and the RPM limit; the token count is not a billing unit.

That changes the workflow. You stop asking “is this retry worth the tokens?” and start asking “is this retry likely to fix the bug?” The unlimited page explains the exact limits.

What metered is good for

A Token Plan or a pay-per-use balance is still the right tool for some jobs: occasional API calls, a small side project, a one-off batch, or a workload with a predictable ceiling. You pay for what you use and you can stop.

The mistake is using a metered balance for an agent that runs all day and then being surprised by the balance. Metered pricing rewards small, predictable usage. Unlimited pricing rewards iteration.

How to choose

Use the plan price as the break-even line. If your metered usage in a month would cost more than the monthly plan, the unlimited plan is the simpler and usually cheaper choice. Pro is $40 a month, Max is $55, and Ultra is $100 a month or $20 a day.

  • All-day agent work: Pro or Max.
  • Frontier models and 14 parallel sessions: Ultra.
  • A weekend project with a known size: Token Plan.
  • A quick integration test: pay-per-use.

Still unsure? Start with the 500K-token trial on the base models, then move to a plan when the trial stops being enough. The pricing page has the full comparison.

FAQ

Pricing questions.

Is unlimited really unlimited?
For tokens and requests, yes. There is no token quota and no request cap. The limit is parallel sessions and a tiered RPM: 60 for Pro, 120 for Max and 240 for Ultra.
What happens if I hit the parallel session limit?
Extra requests wait or fail with a clear error until a session is free. Upgrade to a higher plan if this happens often.
Can I switch from metered to unlimited later?
Yes. Buy the plan in the Telegram bot and the same key keeps working. The remaining metered balance is separate from the subscription.
Do Token Plans expire?
Token Plans are valid for 30 days. Pay-per-use balances do not expire.
Which plan do most agent users pick?
Pro is enough to start. Max is the common upgrade when several sessions run at once; Ultra is for the frontier models and 14 parallel sessions.
