Setup

Already on the OpenAI or Anthropic SDK? Change two lines.

Point the base URL at Develop & Hack_With_Ai and use your sk- key. Your client stays the same.

Claude Code Codex Cursor Cline OpenCode Kilo Code

Full setup guide

python 
from openai import OpenAI

OPENAI_BASE_URL = "https://freeai.jembatanai.com/v1"

client = OpenAI(
    base_url=OPENAI_BASE_URL,
    api_key="sk-...",
)

reply = client.chat.completions.create(
    model="anthropic/claude-sonnet-5",
    messages=[{"role": "user", "content": "Hello!"}],
)

print(reply.choices[0].message.content)
python 
from anthropic import Anthropic

ANTHROPIC_BASE_URL = "https://freeai.jembatanai.com"

client = Anthropic(
    base_url=ANTHROPIC_BASE_URL,
    api_key="sk-...",
)

reply = client.messages.create(
    model="anthropic/claude-sonnet-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello!"}],
)

print(reply.content[0].text)
curl 
curl https://freeai.jembatanai.com/v1/chat/completions \
  -H "Authorization: Bearer sk-..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-sonnet-5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
Only the base URL and the key change. The rest is your code.

Data and reliability

We do not sell customer data

We store usage metadata for billing, quota and abuse prevention. Conversation content is forwarded to the model provider so your request can be answered.

No training on your traffic

Requests are forwarded to the provider you picked and answered there. Nothing in a prompt or a completion is kept by Develop & Hack_With_Ai.

Metadata for billing

Model, token counts, latency and status are stored so quota and invoices add up. That metadata is the only thing kept.

One key, one person

Every plan carries one API key for personal use. A key shared by many people is revoked, which keeps quota honest for everyone.

Read the privacy policy or call GET /v1/quota to see what is tracked on a key.

FAQ

Frequently asked questions

Not answered here? Our support bot replies right away on Telegram.

Which payment methods are accepted?
Contact us on Telegram to pay and buy. We accept all payment methods as well as crypto.
How soon is the key delivered after paying?
Automatically, as soon as the payment is confirmed. The Telegram bot delivers the key. For crypto, confirmation waits for the number of blocks each network requires.
Can I get a refund?
All purchases are final, and service disruptions are not refunded. We fix three things: a double payment, a payment whose product was never delivered, and a wrong product that has not been used. Submit it through the bot within 7 days of paying.
Does it work with the OpenAI and Anthropic SDKs?
Yes. The OpenAI format through /v1/chat/completions and /v1/responses, the Anthropic format through /v1/messages, with the same key.
Which clients can I use?
Claude Code, Codex, Cursor, Cline, OpenCode and Kilo Code have guides in the documentation. Other clients that accept an OpenAI or Anthropic base URL usually work too.
How many keys does a plan include?
One API key for personal use. A key shared by many people is revoked.
What happens when a plan expires?
The key stops serving requests until the plan is renewed. Renewals for the same key are bought in the Telegram bot.
How do I check my remaining quota?
Call GET /v1/quota with the same key. The answer carries the plan status, the validity, usage over the last 30 days and the token or dollar balance left on this key.
